In 26.1 most recipe types have been combined into one recipe using Triggers, Conditions, Results and Options.

This recipe type is called "inworldrecipes:world_recipe"

# Triggers
Triggers are what cause the recipe to run, multiple triggers can be used and all triggers must be satisfied for the recipe to run.

## Click Type
Can be "left" or "right" clicking a block in world
```js
      "type": "inworldrecipes:click_type",
      "click_type": "left_click"
```

## Target Block
The block that must be targeted for recipe to trigger, pairs well with click type. Uses either
```js
   {
      "type": "inworldrecipes:block_target",
      "target_block": {
        "Name": "minecraft:grass_block"
      }
    }
```

## Lightning Strike
Triggers when a lightning strike happens within a 3 block range of the target area. If missing uses false
```js
    {
      "type": "inworldrecipes:lightning"
    }
  ],
```

## Standing On
Triggers when the player is standing on a certain block
```js
   {
      "type": "inworldrecipes:standing_on",
      "target_block": {
        "Name": "minecraft:grass_block"
      }
    }
```

## Block Landed
Triggers when a block lands
```json
    {
      "type": "inworldrecipes:block_landed",
      "block": "minecraft:sand"
    }
```
## Chat Message
Requires a certain message to be sent in chat
```json
    {
      "type": "inworldrecipes:chat_message",
      "message": "Hi Chat"
    }
```

## Fluid
Triggers when the target position contains a matching fluid (a placed water/lava source or flowing block, or any modded fluid). `fluid` accepts a single fluid id or a `#tag`.

Optionally takes an `items` list (SizedIngredient format). When `items` is present, the item(s) must be physically floating in the fluid, and the recipe will trigger automatically roughly every half second while they're there — no click trigger is needed for this case. Pair with `inworldrecipes:consume_fluid_items` in the results to remove them once the recipe fires.
```json
    {
      "type": "inworldrecipes:fluid",
      "fluid": "minecraft:lava",
      "items": [
        {
          "ingredient": "minecraft:sand",
          "count": 1
        }
      ]
    }
```

## Cauldron
Triggers when the target position is a water or lava cauldron holding the matching fluid. `fluid` accepts a single fluid id or a `#tag`.

`consume_level` (1-3, default 1) is the minimum fluid level the cauldron must have for the trigger to match, and doubles as the amount consumed by the `inworldrecipes:consume_cauldron_fluid` result (lava cauldrons have no partial levels, so any consumption empties them fully).

Optionally takes an `items` list (SizedIngredient format), same as the Fluid trigger above - when present, the item(s) must be floating in the cauldron and the recipe triggers automatically roughly every half second while they're there, no click required. Pair with `inworldrecipes:consume_cauldron_items` in the results to remove them once the recipe fires.
```json
    {
      "type": "inworldrecipes:cauldron",
      "fluid": "minecraft:water",
      "consume_level": 1,
      "items": [
        {
          "ingredient": "minecraft:clay_ball",
          "count": 1
        }
      ]
    }
```

# Conditions
Conditions are what must be true for the recipe to run, multiple conditions can be used and all conditions must be satisfied for the recipe to run.

## Held Item
Player must be holding a certain item, uses either. Uses SizedIngredient format
```js
    {
      "type": "inworldrecipes:held_item",
      "ingredient": {
        "ingredient": "minecraft:stick",
        "count": 1
      }
    }
```

## Dropped Items
Must have these items in the area when the recipe is triggered, uses a List<SizedIngredient>
```js
    {
      "type": "inworldrecipes:dropped_items",
      "items": [
        {
          "ingredient": "minecraft:dirt",
          "count": 3
        },
        {
          "ingredient": "minecraft:stone",
          "count": 3
        }
      ]
    }
```

## Inventory Items
Must have these items in the inventory when the recipe is triggered, uses a List<SizedIngredient>
```js
    {
      "type": "inworldrecipes:inventory_items",
      "items": [
        {
          "ingredient": "minecraft:dirt",
          "count": 3
        }
      ]
    }
```

## Weather
Must be a certain weather when the recipe is triggered, can be "clear", "rain", "thunder", "snow". If missing uses nother and any weather will work. Note the weather set to rain will also work for thunder but thunder recipes will not work in rain
```js
    {
      "type": "inworldrecipes:weather",
      "weather": "rain"
    }
```

## Entity
Requires a certain entitiy or entites to be around the area of the trigger, accepts nbt and can also damage the entity
```json
    {
      "type": "inworldrecipes:entity",
      "requirements": [
        {
          "type": "minecraft:cow",
          "nbt": {
            "variant": "minecraft:cold"
          },
          "damage": 2.0
        },
        {
          "type": "minecraft:pig",
          "damage": 10.0
        }
      ]
    }
```

# Results 
Results are what happens when the recipe is triggered and all conditions are satisfied, multiple results can be used and all results will happen when the recipe is triggered.

## Chance Results
Chance results have a chance to happen when the recipe is triggered, uses a List<ChanceResult>, also requires add_to_inventory
```js
    {
      "type": "inworldrecipes:chance_results",
      "add_to_inventory": true,
      "results": [
        {
          "item": {
            "id": "minecraft:acacia_log",
            "count": 2
          },
          "chance": 0.5
        },
        {
          "item": {
            "id": "minecraft:emerald",
            "count": 7
          },
          "chance": 1.0
        }
      ]
    }
```

## Output Blockstate 
Changes the blockstate of the target block or standing on block to the specified blockstate
```js
    {
      "type": "inworldrecipes:block_state",
      "block_state": {
        "Name": "minecraft:dirt"
      }
    }
```

## Consume Inventory Items
If the Inventory Items are consumed they will be taken with the same count as the recipe requires, if the count is not specified it will consume 1 of each inventory item. Uses true or false. If missing uses false
```js
    {
      "type": "inworldrecipes:consume_inventory_items"
    }
```
## Consume Held Item
If the held item required is consumed
```jsons
    {
      "type": "inworldrecipes:consume_held_item",
      "count": 64
    }
```
## Damage Held Item
If the held item is damaged
```js
    {
      "type": "inworldrecipes:damage_held_item",
      "amount": 64
    }
```

## Consume Dropped Items
If the Dropped Items are consumed they will be taken with the same count as the recipe requires, if the count is not specified it will consume 1 of each dropped item. Uses true or false. If missing uses false
```js
    {
      "type": "inworldrecipes:consume_dropped_items"
    }
```

## Chat Message
Prints a chat message to the player that triggered the event
```json
    {
      "type": "inworldrecipes:message",
      "message": "The spirits have heard your call... heres a bed you can sleep in",
      "action_bar": true
    }
```

## Consume Cauldron Fluid
Lowers the cauldron's fluid level by the `consume_level` configured on the recipe's `inworldrecipes:cauldron` trigger, emptying it back to a plain cauldron once the level reaches zero (lava cauldrons always empty fully, since they have no partial levels). Requires the recipe to have a `cauldron` trigger.
```json
    {
      "type": "inworldrecipes:consume_cauldron_fluid"
    }
```

## Consume Cauldron Items
Consumes the `items` required by the recipe's `inworldrecipes:cauldron` trigger from the cauldron itself. Requires the recipe to have a `cauldron` trigger with an `items` list - without this, items left in the cauldron will keep re-triggering the recipe.
```json
    {
      "type": "inworldrecipes:consume_cauldron_items"
    }
```

## Consume Fluid Items
Consumes the `items` required by the recipe's `inworldrecipes:fluid` trigger from the fluid itself. Requires the recipe to have a `fluid` trigger with an `items` list - without this, items left in the fluid will keep re-triggering the recipe.
```json
    {
      "type": "inworldrecipes:consume_fluid_items"
    }
```

## Consume Fluid
Removes the fluid at the trigger position - a plain fluid block is set to air, a waterlogged block just has its waterlogged flag cleared (the rest of the block is left alone). `chance` (0.0-1.0, default 1.0) is the chance this happens each time the recipe fires, eg 0.2 is a 20% chance to consume the fluid on craft.
```json
    {
      "type": "inworldrecipes:consume_fluid",
      "chance": 0.2
    }
```

# Options
Options are extra settings for the recipes eg showing the recipe in jei or making the recipe just visible in jei and not actually do anthing. Useful for showing methods from other mods that use world related mechanics like right clicking a block with an item or standing on a block. Allows you to show these in jei without effecting the mods own behavior.

## Show in JEI
Shows the recipe in jei, uses true or false. If missing uses true
```js
    {
      "show_in_jei": true
    }
```

## Only Visual Recipe
Shows the recipe in JEI, but it doesn't actually do anything, useful for showing methods from other mods that use world related mechanics like right clicking a block with an item or standing on a block. Uses true or false. If missing uses false
```js
    {
      "show_in_jei": true,
      "only_visual_recipe": false
    }
```

Throwing sand into water converts it into glass, no click required, with a 20% chance of using up the water in the process:
```json
{
  "type": "inworldrecipes:world_recipe",
  "triggers": [
    {
      "type": "inworldrecipes:fluid",
      "fluid": "minecraft:water",
      "items": [
        {
          "ingredient": "minecraft:sand",
          "count": 1
        }
      ]
    }
  ],
  "conditions": [],
  "results": [
    {
      "type": "inworldrecipes:consume_fluid_items"
    },
    {
      "type": "inworldrecipes:consume_fluid",
      "chance": 0.2
    },
    {
      "type": "inworldrecipes:chance_results",
      "add_to_inventory": false,
      "results": [
        {
          "item": {
            "id": "minecraft:glass",
            "count": 1
          },
          "chance": 1.0
        }
      ]
    }
  ],
  "options": [
    {
      "show_in_jei": true
    }
  ]
}
```
